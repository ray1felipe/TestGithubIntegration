# TestGithubIntegration

A small Python workspace containing a Hello World example.

## Requirements

- Python 3.14.8
- Visual Studio Code (optional)

## Run

From the workspace folder, run the script with the workspace virtual environment:

```powershell
.\.venv\Scripts\python.exe hello.py
```

Expected output:

```text
Hello, world!
```

If the virtual environment has not been created yet, create it with an installed
Python 3.14 interpreter:

```powershell
py -3.14 -m venv .venv
```

Open `TestGithubIntegration.code-workspace` in VS Code to use the workspace
settings and select the project interpreter.
